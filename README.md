#  Reflections on Markdown 

## what is markdown  ##
**Markdown is a plain text formatting syntax that is a text-to-HTML conversion tool**, so this makes the basic assumptions about how the document is supposed to be converted to HTML. Markdown is used as a simple way of making an HTML website 
.*It makes writing HTML code easier, but the downside is that you lose the creative freedom to add any details you would like. When I worked with VS Code and made my own website with HTML, it gave me all the creative freedom, then I worked with Markdown.*
