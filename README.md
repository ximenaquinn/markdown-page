#  Reflections on Markdown 

## what is markdown  ##
** Markdown is a plain text formatting syntax that is a text-to- html conversation tool** so this makes the basic assumptions about how the document is supposed to be converted to HTML. Markdown is used as a simple way of making an HTML website 
. It makes writing HTML code easier, but the downside of making it easier  means that you lose the creative side of making any details you would like.
